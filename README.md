# PWA Release Reader & Toolkit 2.5 RC5

This is a **beginner-first learning and diagnostic release candidate**. It is **not** a certified one-click app-store publishing product.

## Start here

1. Unzip the full archive to Documents. Do not run tools from inside a compressed ZIP.
2. Open `index.html` through a local HTTP server or visit the GitHub Pages deployment after publishing this folder.
3. Open `pwa-release-toolkit/README_RC5.md` and follow the Excel dashboard setup.
4. Read the cookbook pathway in the book, one chapter at a time. Record your actual results, not assumed success.

The reader includes **38 chapters and nine appendices**. The previous long-form wording is preserved only inside clearly marked optional historical reference sections; do not rely on archived commands or store policies without verification.

The original RC4 source book is retained at `pwa-release-toolkit/ORIGINAL_BOOK_RC4_FOR_REFERENCE.json` for change auditing.

## Limits

Excel VBA installation must be verified on Windows Desktop Excel; the included legacy deployment, signing, and CI template workflows are disabled and unverified. Actual native builds and Apple/Google submissions require further human steps.
