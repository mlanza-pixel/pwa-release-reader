# RC13 guided cookbook revision

The current book was edited using the RC12 chapter-by-chapter audit. All 42 chapters received an additional task-specific instruction, example and verifiable outcome. All nine appendices now start with a safer quick-reference section. Part VIII (Excel toolkit setup) now appears before Part I in reader navigation, but chapter numbers and permanent link IDs were preserved.

## Important limitations

This is a substantial source-level instructional revision, **not** a live human usability study or full sentence-by-sentence technical certification. Screens are simulated teaching examples. Apple/Google account screens and store rules change. The current Excel/VBA builder and native signing/publishing steps still require Windows and device-level testing. The native-build workflows are disabled templates. Existing historical archived documents are retained and may contain old version labels.

The updated release does not implement a certified one-click Prepare My App feature or real store submission.
