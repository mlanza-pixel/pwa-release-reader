# PWA Release Reader & Toolkit v2.5 RC12 — Friendly Cookbook

This revision rewrites all 42 numbered chapters and the primary instructions in all nine appendices, making the book warmer and easier to follow without pretending that any software is automatically working.

Open `index.html` through the published website or a local web server; do not simply double-click the HTML file, because the reader loads `content/book.json`.

For a Windows toolkit test, use the existing `pwa-release-toolkit` folder. It remains RC11-era runtime code: **the book has advanced to editorial RC12, while Windows macro behavior has not been recertified**. For traceability, previous scripts are retained unchanged and should not be labeled RC12 certified.

See `EDITORIAL_REVIEW_RC12.md` for each chapter's before-and-after text length and outstanding verification gates.

The reader also retains complete prior appendix reference entries behind expandable **Additional reference** sections, clearly marked as older material that needs up-to-date confirmation. This avoids losing the glossary and FAQ while keeping the main path short.
