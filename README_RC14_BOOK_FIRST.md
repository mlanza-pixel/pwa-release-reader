# PWA Release Reader v2.5 RC14 — Website-First Illustrated Cookbook

**Start here:** Open the reader and select **Before You Start: The Whole Story in 8 Pictures**. The eight original illustrations are restored on that page. Then follow **Start Here 1–3** to recognize an existing website, add/review a manifest and optional service worker, test locally, and make a safe GitHub copy.

**Book layout:** Parts I–VII follow the three Start Here lessons. Part VIII (Windows Toolkit, Chapters 39–42) is now immediately before the bold, highlighted Appendices section. The 42 numbered chapters and nine appendices retain their IDs so existing links do not shift. All 42 chapters have additional contextual explanations.

**Starter project:** `pwa-release-toolkit/starter-pwa/` contains an independently runnable sample with index.html, a web manifest, icons, a service worker, a read-only Python checker and a complete README. Do not overwrite your own PWA with these sample files.

**Excel:** The `.xlsx` includes a new `PWA First Steps` worksheet and a corrected `Reading Order` worksheet. The macro builder is inherited from RC13 and has **not** been executed in Windows Excel in this release. The generated `.xlsm` has not been certified. This is a book and sample-project update, not a validated new installer.

**Known limitations:** Existing simulated illustrations may not match today's screens. Existing toolkit signing/deploy workflows remain blocked or unverified. Real browser/offline testing is needed on the user's Windows machine; static testing and the starter-file checker cannot certify install behavior or app-store publication.
